# River Morphological and Hydrological Analysis

This repository contains a Python-based automated workflow for extracting river morphological parameters, mapping channel migration over time, and estimating regime scour depths under design flood conditions. The workflow integrates Google Earth Engine (GEE) satellite imagery processing, raster map algebra, and hydraulic calculations, culminating in a programmatically generated slide presentation.

The case study focuses on an 80 km reach of the braided Brahmaputra River in Assam, India.

## Repository Structure

* `morphology_analysis.ipynb`: Core research notebook detailing GEE authentication, Sentinel-2 median compositing, NDWI calculations, and initial scour estimations.
* `generate_report_and_ppt.py`: Fully automated pipeline script. It executes GEE analysis, computes morphology metrics, generates matplotlib plots, downloads GIS map thumbnails, and builds the slide deck.
* `Brahmaputra_Hydrological_Assessment.pptx`: The widescreen slide deck generated by the script, presenting the methodology, tables, plots, and engineering recommendations.
* `river_migration_map.png`: Multi-temporal migration map showing erosion, accretion, and stable zones.
* `scour_comparison.png`: Comparison chart of Lacey versus Blench scour depths across morphological zones.
* `brahmaputra_reach.png`: Sentinel-2 true-color reach composite.

## Features

### 1. Automated River Morphological Parameter Extraction
* Uses Sentinel-2 MSI Harmonized Level-2A surface reflectance data.
* Applies Normalized Difference Water Index (NDWI) thresholding to extract wet channel areas during dry-season low flows.
* Implements a connected-pixel filter to remove off-channel agricultural ponds and noise.
* Computes exact surface area via pixel-wise area integration (`ee.Image.pixelArea`) and estimates reach-averaged width.

### 2. Multi-Temporal Channel Migration Mapping
* Compares winter low-flow channels between 2019-2020 and 2023-2024.
* Uses raster subtraction (Map Algebra) on unmasked binary water layers to classify transition zones:
  * Stable Channels: Persistent water in both years.
  * Accretion Zones: Water transitioning to land (sandbar/char growth).
  * Erosion Zones: Land transitioning to water (bank retreat and channel shifts).
* Exports a composite GIS image overlaying these layers onto a darkened true-color satellite background.

### 3. Scour Depth Estimation and Evaluation
* Computes Lacey's regime scour depth using silt factors.
* Computes Blench's scour depth using bed factors based on particle sizes.
* Applies Indian Standard (IS:13757 / IRC:89) multipliers to estimate maximum scour depth across straight reaches (1.27x), moderate bends (1.50x), and severe bends (2.00x).
* Saves a styled, publication-ready comparative bar chart matching the dark-theme presentation.

### 4. Automated slide generation
* Installs required packages on execution.
* Uses `python-pptx` to build a 7-slide, 16:9 widescreen presentation.
* Implements a custom dark-mode theme (Slate-900 background with sky-blue and teal accents) using pixel-perfect coordinate grids to avoid text and image overlapping.

## Setup and Execution

### Prerequisites
1. **Python Environment:** Ensure Python 3.10+ is installed. The script is configured to auto-install missing packages on startup.
2. **Earth Engine Credentials:** The script relies on an authenticated Earth Engine account. Initialize the command line:
   ```bash
   earthengine authenticate
   ```

### Execution
Run the automated script using python:
```bash
python generate_report_and_ppt.py
```
Or if running inside a specific conda environment:
```bash
conda run -n river_morph python generate_report_and_ppt.py
```
Upon successful completion, the script will output the PPT report and local images to the root directory.
